## 2. Profit-Sharing Model

| Parameter | Value |
|-----------|-------|
| **Distribution Frequency** | Monthly (Triggered by `QueenOrchestrator`) |

### 2.1 Formula

```
Net Revenue = (Total Revenue - Compute/API Costs - Treasury Reserve)
Investor Share = (Net Revenue × Investor Percentage)
```

### 2.2 Investor Tiers & Asset Classes

Per the immutable logic in `hive/utils/economy.py`, rewards are distributed based on contribution type and authority level.

#### Tier 1: Principal Architects (Root Authority)

| Parameter | Value |
|-----------|-------|
| **Stake** | ≥ 10% |
| **Members** | Founding Team: Fuzzywigg, Pappas, NFT2.me |
| **Asset Class** | Real Crypto Value (ETH, BTC, SOL) |
| **Payout** | Immediate priority via hardcoded wallets in `hive/treasury.json` |
| **Privileges** | Direct command authority over the Hive |

#### Tier 2: Strategic Partners

| Parameter | Value |
|-----------|-------|
| **Stake** | 5–9% |
| **Members** | Early infrastructure partners |
| **Asset Class** | Hybrid (DAO Credits + Performance-based ETH) |
| **Payout** | Standard monthly distribution |

#### Tier 3: Community Backers

| Parameter | Value |
|-----------|-------|
| **Stake** | < 5% |
| **Members** | Donors, Micro-investors |
| **Asset Class** | DAO Credits (Non-voting governance tokens) |
| **Payout** | Accumulation of loyalty points/credits in `intel.json` |

| Parameter | Value |
|-----------|-------|
| **Source of Truth** | `hive/honeycomb/state.json` (Economy Section), `intel.json` (Sponsor Pipeline) |

### 3.1 Monthly Automated Report

Generated by the **Finance Bee** (planned) or `SponsorHunterBee`:

| Section | Contents |
|---------|----------|
