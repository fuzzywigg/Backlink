## Task 1: Update Existing Documentation

When the user asks to update documentation:

1. Identify the target file in `docs/` folder
2. Make the requested edits to the Markdown file
3. Rebuild the site:
// turbo

```bash
python -m mkdocs build
```

4. Deploy to Firebase:

```bash
firebase deploy --only hosting
```

5. Confirm deployment at <https://smtp-ai-5be89.web.app/>

---

## Task 2: Add New Content or Pages

When the user asks to add new content:

1. Create a new `.md` file in the appropriate `docs/` subfolder:
   - `docs/planning/` - Roadmaps, strategies, plans
   - `docs/lore/` - Station manifesto, personas, music logic
   - `docs/protocols/` - Interaction protocols, memory constitution
   - `docs/archive/` - Historical or deprecated content

2. Update `mkdocs.yml` to include the new page in the `nav:` section

3. Rebuild and deploy:
// turbo

```bash
python -m mkdocs build
```

```bash
firebase deploy --only hosting
```

---

## Task 3: Deploy a Public Webpart or Tool

When the user asks to deploy a standalone HTML tool or webpart:

1. Create the HTML/CSS/JS file in the `docs/` folder (or appropriate subfolder)
   - For interactive tools: Include all JS inline or in the same folder
   - For static content: Standard HTML is fine

2. If using external assets:
   - Place images in `docs/assets/`
   - Reference them with relative paths

3. Add to `mkdocs.yml` nav if it should appear in navigation

4. Rebuild and deploy as above

**Example webparts already deployed:**

- `songs.html` - Song library with YouTube Music links

---

## Task 4: Quick Deploy (No Content Changes)

If mkdocs has already been built and you just need to push:

// turbo

```bash
firebase deploy --only hosting
```

---

## Task 5: Preview Locally Before Deploy

To preview changes before deploying:

// turbo

```bash
python -m mkdocs serve
```

This starts a local server at `http://127.0.0.1:8000/`

---

## Task 6: Sync GitHub After Deploy

After any documentation changes, commit and push:

// turbo

```bash
git add docs/ mkdocs.yml
git commit -m "docs: Update documentation"
git push origin main
```

## Common Issues

### "mkdocs not found"

Run: `pip install mkdocs mkdocs-material`

### "firebase not found"

Run: `npm install -g firebase-tools` then `firebase login`

### File not appearing on site

- Check that it's listed in `mkdocs.yml` under `nav:`
- Ensure the file path is correct (relative to `docs/` folder)
