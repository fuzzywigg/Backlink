## 🚀 QUICK START

1. Double-click `install_watchtower.bat`.
2. It will create a config file (`hunter_config.json`).
3. Add the wallet addresses you want to watch.
4. The system will launch and monitor 24/7.

## 🛠 CONFIGURATION

Edit `hunter_config.json`:

```json
{
  "target_wallets": [
    { "address": "0xYourWallet...", "label": "My Vault" },
    { "address": "0xHacker...", "label": "The Enemy" }
  ],
  "notifications": {
    "console_alert": true,
    "log_file": "evidence_locker.json"
  },
  "rpc_url": "https://eth.llamarpc.com"
}
```
